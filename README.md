# Cosmetic X - одностраничный интернет-магазин аксессуаров.

## Стек

- **React 19**
- **TypeScript 5.9**
- **Vite 8**
- **vanilla CSS**

## Возможности

- Главная страница с hero-секцией, категориями, списком продуктов
- Адаптивный header с рекламной строкой и боковой навигацией
- Страницы авторизации и регистрации с собственным layout (**без backend**)
- Кастомная 404-страница
- Плавные анимации появления секций
- Полноэкранные видео-баннеры в hero/категориях
- Кнопка наверх с автоскрытием
- Локальные шрифты

## Структура проекта

```
src/
├── app/            # Корневая обёртка приложения, layouts и глобальные стили
├── pages/          # Пользовательские страницы
├── widgets/        # Композитные блоки
├── entities/       # Бизнес-сущности
├── shared/         # Переиспользуемые UI, хуки, шрифты, изображения и видео
└── main.tsx        # Точка входа
```

## Запуск

```bash
# установка зависимостей
npm install

# dev-сервер
npm run dev

# production-сборка в dist/
npm run build

# локальный предпросмотр production-сборки
npm run preview

```

## Лицензия

Учебный проект, распространяется как есть.
